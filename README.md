## 🛠️ Technical Skills Ecosystem

### 📱 Flutter & Dart
- **Flutter Framework**: Production cross-platform mobile development (Android, iOS, Web).
- **Dart Language**: Object-Oriented Programming (OOP), asynchronous programming (Streams, Futures, Isolates).
- **Responsive UI Engineering**: Dynamic layouts adapting across Mobile, Tablet, and Desktop breakpoints.
- **Custom Widget Architecture**: Reusable atomic widget libraries, CustomPainters, and complex Canvas rendering.
- **Animations & Micro-interactions**: Implicit & explicit animations, staggered transitions with `flutter_animate`.
- **Navigation & Routing**: Declarative routing, multi-stack bottom navigation, and deep linking.

### 🏛️ Architecture & Design Patterns
- **Clean Architecture**: Strict separation of concerns across **Data**, **Domain**, and **Presentation** layers.
- **MVVM Pattern**: Decoupling UI logic from reactive ViewModels and state notifiers.
- **Feature-Based Modular Architecture**: Scalable folder and module structure engineered for 100+ to 200+ screen applications.
- **Repository Pattern**: Abstracting data access layer between remote network endpoints and local databases.
- **Reusable Component Systems**: Design tokens, consistent theme systems, and atomic UI components.

### ⚡ State Management
- **GetX**: Reactive state management (`Rx`, `Obx`), dependency injection (`Get.find`, `Get.put`), and route management.
- **Provider**: Structured state propagation, `ChangeNotifier`, and selector-based rebuild optimization.
- **RxDart**: ReactiveX reactive stream programming (`BehaviorSubject`, debounce, combineLatest, event transformers).

### 💾 APIs, Local Database & Backend
- **REST API Integration**: HTTP client / Dio with JSON serialization, JWT authentication interceptors, and error handling.
- **Local Relational Database**: **SQLite / Sqflite** — Table schema design, offline caching, and ACID CRUD queries.
- **Local Key-Value Storage**: `SharedPreferences` and `Hive` for session state and fast preferences caching.
- **Firebase Services**: Firebase Authentication (Email/Password, OAuth, Social Login), Cloud Firestore, and Cloud Messaging (FCM).

### 🧠 Computer Science Fundamentals
- **Data Structures (Basic Knowledge)**: Arrays, Linked Lists, Stacks, Queues, and dynamic collections.
- **OOP Principles**: Encapsulation, Inheritance, Polymorphism, and Abstraction.
- **Memory & Performance**: Minimizing widget rebuilds, optimizing memory footprints, and asset caching.

### 🔧 Tools & Workflow

## ⚡ Getting Started & Running Locally

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (version 3.19.0 or higher recommended)
- [Dart SDK](https://dart.dev/get-dart)
- Chrome / Edge browser (for Flutter Web) or an Android/iOS emulator

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rakibul-hossain/flutter_protfolio.git
   cd flutter_protfolio
   ```

2. **Install Flutter dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run on Chrome (Web Development)**:
   ```bash
   flutter run -d chrome
   ```

4. **Build Production Web Bundle**:
   ```bash
   flutter build web --release
   ```
